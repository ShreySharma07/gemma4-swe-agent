# Null-model dial survives; the RL method does not

**Bottom line.** Six rounds of inventing and breaking did not produce what the brief asked for: a novel PEFT + RL method that improves LLM reasoning over *large* directed graphs. What survived is narrower. **Architecture v3, the "null-model dial"**, is LoRA SFT on execution-labelled counterfactual call-set items. The items are generated by a nested family of graph null models (degree only; degree + level; degree + level + module; edge count only) applied to real traced call graphs. The question it asks is whether reliance on each topology-statistic family (module locality, depth level, local motifs) falls specifically for the families the training null destroys. The last prior-art pass rated that claim **NARROWED**, not new. Sinha et al.'s nested n-gram shuffles, Geirhos/Hermann cue-decorrelation, Early Cue Precision and null-model graph augmentation all share the mechanism. Only the graph-null, answer-flipping, per-statistic specificity version is unclaimed. The final verifier returned **NEEDS-FIXES**, with eight required fixes (F1–F8). The biggest problems are these. The budget counts one training epoch but the recipe trains two, so the true total is **24.0 / 33.8 / 59.3 GPU-h** (optimistic / central / pessimistic), not 17.4 / 24.6 / 43.1. The headline metric quietly reintroduced a confound that v2 had fixed. The "only when" specificity test has **≈0.14–0.47 power**. Against the target, PEFT is met; **RL is not met** (it exists only as an untested online drop-in); **large graphs are not met**; near-SOTA is partly met (retention only); **generality is not met**. **Nothing has been run.** No GPU-hour has been spent, no CPU kill test has executed, and every effect size is a guess. The honest decision for Shrey is whether to accept an analysis-instrument paper or keep pushing for an RL method that the 4×L4 offline constraint probably cannot fund.

## What survived is an analysis instrument, not an RL method

**The surviving claim.** It is the v3 null-model dial, as narrowed by the final red team (`break_v3_priorart.md` §4). This is the defensible one-sentence statement:

> "We use a nested family of graph null models (degree / +level / +module, with an edge-count leak), applied to real traced call graphs, as answer-flipping, execution-labelled counterfactual training data for an LLM. Pre-registered prior-vs-displayed-edge conflict probes on real code then test whether reliance on each topology-statistic family falls specifically for the families the training null destroys: a graph-null, per-statistic extension of cue-decorrelation training (Geirhos/Hermann; Sinha et al.'s nested n-gram shuffles) that no prior has run on graphs or LLM code reasoning."

**What must not be claimed.** Each of the following already has prior work:

| Not claimable | Prior work |
|---|---|
| Cue-destroying training data reduces reliance on that cue | Hermann et al. ([1911.09071](https://www.alphaxiv.org/abs/1911.09071), BP3-8); Early Cue Precision ([2606.30344](https://www.alphaxiv.org/abs/2606.30344), BP3-21) |
| Nested statistic-preserving nulls as training data are new | Sinha et al. ([2104.06644](https://www.alphaxiv.org/abs/2104.06644), BP3-5); Xuan et al. ([2112.00476](https://www.alphaxiv.org/abs/2112.00476), A3-N5) |
| Counterfactual SFT lowers prior-over-displayed reliance | LCV ([2601.18352](https://www.alphaxiv.org/abs/2601.18352), BP3-20) |
| Pairing answer-flip counterfactuals in RL is new | CRPO ([2605.21988](https://www.alphaxiv.org/abs/2605.21988), BP2-3) |

## Round 0: the six anomalies hold up, and two are sharper than reported

**Findings.** The inventor re-read the primary sources behind each anomaly and found that two motivating numbers had been misquoted.

**SOG-R1.** The quoted "RL-only 63.0 vs 86.1" was not a collapse. On CWQ, Table 3 gives:

| Setting | CWQ score |
|---|---|
| Base | 35.3 |
| RL-only | **63.0** (+27.7 over base) |
| SFT-only | **86.1** |
| SFT → RL | **88.7** |

The RL uplift over SFT also shrinks as SFT data grows: +7.8 EM at 2.7k questions, but +2.4 at 8.7k ([SOG-R1](https://www.alphaxiv.org/abs/2607.18481), INV-1).

**CNY.** The degree-preserving rewire drops walk accuracy from 76.6 to **73.0**. That equals the "preview + direct, no walking" control (73.4) almost exactly, so the rewire **removes exactly the walk's gain and nothing else**. Walks per node also rise from 1.24 to 2.01 under the rewire, so the model notices and compensates ([CNY](https://www.alphaxiv.org/abs/2608.29588), INV-2).

| # | Anomaly | Status | What the re-read adds |
|---|---|---|---|
| 1 | RepoReasoner call chains: precision 0.814, recall 0.318 | VERIFIED ([2607.25996](https://www.alphaxiv.org/abs/2607.25996), INV-5) | Oracle recall is still **0.355 with zero distractors**, so models emit short lists; noise is not the cause |
| 2 | GRA: the graph-free control is within +0.3 to +1.9 pp | VERIFIED (inherited) | Selective access dominates below a budget knee of about 30 calls |
| 3 | RepoNavigator: 3 extra structural tools cut IoU from 24.28 to 13.71 | VERIFIED (inherited) | The added tools are largely redundant views of `jump` |
| 4 | CNY: rewire 76.6 → 73.0 | VERIFIED | Rewire loss = walk gain. Structure is used for *selection* (≈3.5 pts) |
| 5 | SOG-R1: RL-only vs SFT | **VERIFIED, corrected** | RL-only 63.0, SFT-only 86.1, SFT→RL 88.7, base 35.3 |
| 6 | Incomplete graphs cannot separate unobserved from false edges | ~VERIFIED (inherited) | In code, execution is a third evidence source, but only on covered code |

**Local facts.** Two were computed from the repo's run files (VERIFIED arithmetic, regex-noisy gold).

- **F1.** On tasks with ≥3 gold functions, the v5 localiser wrote `OTHER_LOCATIONS: none` in **72%** of cases and named only **25%** of the gold functions; **2 of 43** resolved. This reproduces RepoReasoner's high-precision, low-recall pattern in our own agent.
- **F2.** Reproducing the bug before editing does not pay off as currently done: 2/17 resolved with reproduction against 24/112 without.

**Decision.** Treat structure as a *selection* aid. Treat under-enumeration of sets as the sharpest graph-shaped failure in our agent.

**Next step.** Generate mechanisms per anomaly.

## Rounds 1–2: twelve signals, cut to six by surprise and cheap testability

**Findings.** The inventor produced the following inputs:
- three mechanisms per anomaly, 18 in total, each paired with a signal that works only if that mechanism is real;
- eight assumption inversions, such as "the graph is an output, not an input" and "tests are sensors, not only rewards";
- an ideal-observer analysis. The ideal per-action signal is the change in the log-posterior of the true fix. Its two cheapest approximations are a privileged self-teacher and an SBFL posterior over the agent's own experiments.

These were distilled into 12 ideas.

| # | Idea | Core signal | To Phase 2? |
|---|---|---|---|
| 1 | **CASE**: atomised set emission | One calibrated decision per candidate, scored by a proper log score against trace labels | ★ |
| 2 | Depth-IPW recall reward | Reward each recovered node by 1/base-recall at its executed depth | Became a stratum of CASE |
| 3 | Dark-edge ranking | Reciprocal rank of trace-witnessed callees with no lexical cue | Became a diagnostic |
| 4 | **ERC**: executable rewire counterfactuals | Degree-preserving call-target swaps, executed; predict which tests flip | ★ |
| 5 | Backward-hop asymmetry | Caller vs callee recall from traces | Became a diagnostic |
| 6 | **ALIAS**: observation-equivalent action marginal | −log Σ π over executable aliases that return the same facts | ★ |
| 7 | **SENSOR**: tests as sensors | Δ log p(F*) under an SBFL posterior built from the agent's own experiments | ★ |
| 8 | **GCSR**: graph-compiled synthetic repos | Compile a typed graph into a buggy Python package; separate protocol learning from content | ★ |
| 9 | Privileged-scaffold generation | Generate with the executed subgraph in the prompt, train without it | Ablation of 10 |
| 10 | **SAST**: structure-ablated self-teacher | Teacher log-ratio with the true vs the rewired privileged graph | ★ |
| 11 | Impact forecasting | Predict which tests change before submitting | Parked |
| 12 | Tri-state execution grounding | +1 supported / −λ contradicted / 0 unobserved | Became CASE's labelling rule |

**Decision.** Six ideas went to Phase 2: CASE, ERC, ALIAS, SENSOR, GCSR and SAST. The other six were folded in as diagnostics or ablations.

**Next step.** Critic and red team.

## Round 3: the critic and red team killed or narrowed every idea

**Findings.** The critic applied three kill rules: 25 GPU-h in total, a falsifiable kill test, and no same-mechanism prior work. **All six ideas failed rule 1 or rule 2 as written.** The critic's cross-cutting findings changed every later budget:
- an unbudgeted ≈1 GPU-h training probe;
- evaluation costs 1.8–3.4 GPU-h per arm;
- the minimum detectable effect on dev resolve at n=129 is ≈7–9 pp;
- raw trajectories are not stored locally;
- 62 of the 129 dev tasks come from requests, rich and httpx, so training on those repos contaminates the dev set.

The red team searched for same-mechanism prior work. Its results are below, with the top two ideas by surprise getting the extra round the brief specified.

## Round 4: GRAFT v1 broke on reward gaming, shortcuts and an invalid budget

**Findings.** GRAFT compiled real traced call graphs into executable Python repositories and injected bugs, including a new "degree-preserving call-target swap" (DPCS). It trained three arms that differed only in topology:
- **(b)**: topology copied from real repos;
- **(c)**: a degree- and depth-matched rewire of (b);
- **(d)**: depth 1.

Training was rejection-sampling SFT, then an offline clipped-surrogate stage. Evaluation used ≥300 real-repo call-set items. Three breakers attacked it independently. Their top five each:

| Breaker | Top breaks |
|---|---|
| **Logic** (K-01…K-51) | **K-30 + K-31 (fatal):** the set reward averages over listed ∪ gold, so padding with easy negatives beats honest listing. Even "omit all gold + 200 padding" scores −0.027 against honest −0.074. **K-04 + K-12 (fatal):** visible exact unit contracts make "deepest failing contract" a no-traversal localiser, and ~40 fixed templates make body mutations detectable by surface form. Both work equally in every arm, so (b)≈(c) for the wrong reason. **K-21:** the rewire destroys module locality and imports, so (b)>(c) could be a file-locality prior. **K-27/K-28:** arm (d) effectively names the bug and teaches a lexical rule that harms deep strata. **K-50:** one seed per arm with 8 clusters |
| **Method** | **No positive control (fatal):** with ≈15–25 successful trajectories per arm, "nothing moved" is the modal outcome, and an H1 failure would be misread as "content dominates". **Auxiliary items in the eval format differ in depth by arm (fatal for H2/H3 identification).** **8 clusters, 1 seed:** design effect 2.8–4.7; the TOST passes only when training did nothing. **Budget ≈22 / 35 / 58 GPU-h, not 25:** the r3_v5 dev run took 6.45 h sequential (VERIFIED), and the plan budgeted 2.5 h. **Near-SOTA unmeasured** |
| **Prior art** | Compiler: FuncBenchGen ([2509.26553](https://www.alphaxiv.org/abs/2509.26553), BP1-6), DynaCode ([2503.10452](https://www.alphaxiv.org/abs/2503.10452), BP1-33) and SWM hidden channels (BP1-37), all at closeness 2. DPCS is a second-order method-call-replacement mutant: muJava AMR/MMR, MutDafny MCR ([2511.15403](https://www.alphaxiv.org/abs/2511.15403), BP1-10). The rewire readout Δ_struct is CNY plus Huang et al. ([2309.16595](https://www.alphaxiv.org/abs/2309.16595), BP1-20). The H1/H2 thesis was already shown for search agents by PhantomEnvs ([2609.40221](https://www.alphaxiv.org/abs/2609.40221), BP1-28). **Survives:** real vs null topology as a *training* treatment (BP1-38/39 found nothing) |

**Decision.** Rebuild around the one surviving novelty. Make the null model the training signal itself, not just a control arm.

**Next step.** v2.

## Round 5: twin-null RFT v2 died on its own cancellation argument

**Findings.** v2 issued every training task with a **symptom-matched null twin**. The twin keeps the same issue, the same visible failing tests, and the same bodies, names, modules, levels and degrees. Its call graph is rewired, so the correct node is different. The claim was that balanced RFT over both twins cancels credit for any decision taken before the wiring is read. Arms were:
- **M**: both twins;
- **U**: real halves only;
- **N**: null halves only;
- **P**: a real-code positive control.

v2 also fixed almost every v1 break: hidden fresh-input tests, in-family mutations, level- and block-preserving swaps, three data-resampled seeds, 16–20 eval repos, and a retention battery.

The logic breaker and the prior-art breaker then killed the mechanism.

| Break | Severity | Substance |
|---|---|---|
| **L-01 + L-02: cancellation empty in expectation** | Fatal | A blind commit to w earns ½(1{w=v} + 1{w=v′}). Twins cancel only features that differ between v and v′, and the matcher forces those two nodes to share level, module, family and contract status. Bugs are placed synthetically, so v and v′ are exchangeable, and **pairing equals an unpaired 50/50 mixture in expectation**: Credit_M − Credit_U = −½·Δ_H3. v2's own prediction H3 ≈ 0 then implies H2a ≈ H4 ≈ 0, contradicting its +0.12 and −0.25 |
| **L-03: wiring-blind repairs** | Fatal for RFT | Re-implementing the deepest failing contract by fitting its visible values passes hidden fresh-input tests in *both* twins, without reading an edge |
| **L-11 + L-12: weak rewire, tiny supply** | Major→fatal | Family × level × module × arity cells hold ≈0.06 edges each, so **≲6% of edges are rewirable** and H3 "equivalence" is an artefact. Exact symptom matching selects in-degree-1, last-hop differences, and DPCS twins drop to ≈0 |
| L-07 + L-22: dose | Major | Stage B is 1–2 optimiser steps inside warm-up. "0.5M tokens" is ≈3,200 supervised labels |
| L-16 + L-17 + L-21: power | Major | The gatekeeping chain completes with P ≈ 0.02–0.08. Retention non-inferiority passes ≈3–20% of the time even if retention is perfect |
| **Prior art: CRPO** | Closeness 2.5 | Dual-branch GRPO on answer-flipping counterfactual twins, where both branches give gradients so that "shortcut policies cannot be consistently rewarded" ([2605.21988](https://www.alphaxiv.org/abs/2605.21988), BP2-3). Also CAD, Teney and PairCFR at 2 (BP2-12, BP2-OR9); NormWorlds-CF at 2 ([2607.03957](https://www.alphaxiv.org/abs/2607.03957), BP2-23); and the epistemic-POMDP argument for the proof (INFERRED) |

**Decision.** The breakers' own lead (L-01) became the new piece. A null removes credit only for statistics *outside* its preserved set, so a nested family of nulls acts as a dial over which shortcuts stay learnable. RL was dropped. The method was declared to be item SFT up front.

**Next step.** v3, then a red team and an independent verifier.

## Round 6: the v3 dial narrowed again and needs eight fixes

**Findings: red team.** The red team found no prior that trains any model on a *nested hierarchy of graph null models* and reads out *per-statistic* reliance. The searches covered dK-series citers, null-augmentation citers, OpenReview and alphaXiv (BP3-2, BP3-S2-1/2, BP3-OR1–5, BP3-1/14). The mechanism itself is textbook, though:
- Sinha et al. trained on nested n-gram-preserving shuffles plus a unigram "leak" corpus, with minimal-pair probes (BP3-5);
- Hermann et al. found that cue-destroying augmentations shift reliance additively and with a dose-response (BP3-8);
- Early Cue Precision found graded cue–label decorrelation gives a monotone conflict-accuracy dose-response, which is then *overwritten* by one epoch of shortcut-rich fine-tuning (BP3-21).

Three threats are new, not just citations:
- **Cue substitution.** Destroying Loc can *raise* reliance on Lev.
- **Underdetermination.** Coextensive cues give seed spreads up to 0.88 ([2608.24460](https://www.alphaxiv.org/abs/2608.24460), BP3-10).
- **Decorrelation, not removal.** The break arms are 50% real, so the predicted −0.20 is probably optimistic.

**Findings: verifier.**

| Finding | Detail |
|---|---|
| **L5 under-count** (VERIFIED arithmetic) | 26 × 0.75M = 19.5M tokens is *one* epoch. Two epochs is 39M |
| **K-34 regression** (VERIFIED by grep) | v2's plausible-RW, corruption probe, oracle and test-body stratum are absent, yet E2 is now the headline. Locality conflicts deliberately use import-adding far swaps, so H1's predicted +0.15 can come from "content-free SFT trains away plausibility checking" |
| **N1** | Nested break sets are suffixes of one ordering, collinear with rewire strength J. A generic "distrust priors more as rewiring grows" produces every HS β < 0 |
| N2 | Reliance conflates edge-reading skill with prior use |
| N3 | On layered or small graphs, near ≈ mid |
| N4 | Conflict families overlap, and the E2 operators give some arms a home advantage |
| N6 | Shown-set, depth-1 and order leaks in items |
| N7 | Masked SDPA does not make packing cheap, so 900 tok/s has no basis |
| N9 | Real-item length is unstated; at 2.5k tokens the evaluation line grows ≈2–2.5× |
| N10 | Kenward–Roger is infeasible at ≈170k rows; the arm-level df is ≈3 |

**Decision.** Accept the NARROWED tag and apply F1–F8.

**Next step.** Shrey's decisions below.

## The final v3 specification, with the verifier's corrections applied

### Component diagram

```
CPU  S_topo (6–8 non-dev repos) → C1 tracer (setprofile+threading, code-object id; IFG tooling)
       → C2 hygiene (integration roots, SCC cap, effect-only edges, dead code, hub cap) → real DAG G
       → C3 NULL FAMILY: ρ_near (deg+level+module, J≥0.30) · ρ_mid (deg+level, J≥0.50)
                         ρ_far (deg, J≥0.80) · ρ_leak (|E|, J≥0.90) · [F3: + ρ_mod (deg+module)]
       → C4 compiler (total templates, one int domain, random names, positional calls)
       → C5 items: 16-candidate pool, path-complete in both wirings, ≥4 discordant, unary queries
       → day-1 kills K-C1…K-C7 (+K-C4b)
```

## Decision needed from Shrey

**Q1: N arm or P seeds?**
- **Option A** (the budgeted default) has no pure-null arm N, and P keeps 3 seeds. The direct "does real topology matter as training data" question is answered only indirectly.
- **Option B** adds N_mid × 3 (+1.6 h) and cuts P to 2 seeds (−0.5 h).

The final red team strengthened Option B. N_mid is the chance-predictivity end of the dial that decorrelation needs (BP3 §5.3), and it answers the only question `break_v1_priorart` rated SURVIVES.

**Q2: what to do if the probe measures under 500 tok/s.**
- (a) 750 items per adapter (12k labels);
- (b) a 3-point dial (U, mid, far), with M_leak dropped. This makes HS-spec impossible for Loc;
- (c) exceed 25 GPU-h and take quota from the main track.

Given F1 and N7, Q2 is close to certain to fire.

**Q3: apply F1–F8 and start the day-1 CPU kills?** The recommendation is yes. K-C1 through K-C4b and K-C7 cost about two CPU-days and $0. They decide whether a topology shortcut exists to be dialled at all (K-C3), before any GPU-hour is committed. F8 is already done.

**Q4: the strategic question.** It should be put bluntly. The brief asked for a PEFT + **RL** method for **large** graphs that **generalises**. The process converged instead on an analysis instrument for 16-node pools on one model. That convergence was not an accident of the architects; the constraint forced it.

Offline 4×L4 gives an estimated 40–100 rollouts per GPU-h (GUESSED). v2's Stage B amounted to 1–2 optimiser steps. A real RFT dose needs ≥150 trajectories per arm, which is ≥5× the affordable rollouts (L-07). Every RL-shaped idea either became SFT on verified labels or died to prior art: CRPO for paired RL, IGPO for experiment credit, and RLCSD/CROP for self-teacher credit.

The rubric credits analysis as novelty (project memory), so the dial is publishable if its specificity half is powered. The alternatives are:
- (i) pursue the dial paper with F3's double dissociation and Option B;
- (ii) return to the agent-credit line (CERT/Z), where a CPU-only falsifier was already ready;
- (iii) keep looking for an RL method, accepting that it likely needs online compute this project does not have.

Recommendation: (i) only if K-C3 passes on day 1. Otherwise (ii).

## Conclusion

The most useful thing this process produced is not v3. It is a map of why a cheap RL method for graph reasoning keeps reducing to something else. Pairing reduces to mixing in expectation. Shortcut cancellation reduces to cue decorrelation. Offline RFT at this dose reduces to label SFT. Each step down was forced by a breaker's arithmetic, not by taste. The real constraint is that offline 4×L4 cannot fund enough on-policy samples for outcome credit to beat supervised labels the compiler already knows. Under that constraint, the competitive contribution is a *measurement*: which topology cues a quantised model relies on, and whether synthetic training can choose them. That measurement holds only if the day-1 CPU kills show a learnable topology shortcut exists. If K-C3 fails, the dial has nothing to turn, and the project's best paper is still in its agent-credit work rather than in graph reasoning.
