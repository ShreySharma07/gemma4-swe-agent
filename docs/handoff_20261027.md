## 5. Accounts, quota, and rules (learned the hard way)

**Quota:**
- 30 GPU-h per account per week, reset Saturday 00:00 UTC (last reset Oct 24). A 4×L4 session is billed at **2×** wall-clock.
- Model load is ~6 min for vLLM eval and ~37 min for training.
- **Only one 4×L4 session per account at a time.** A second push waits in Kaggle's queue: the Oct 18 v7 arm queued 9.5 h. Run arms one after another, or on two accounts.
- Kaggle's quota display has been inconsistent: it showed Shrey's quota exhausted when our ledger said ~15 h used, and Atul saw readings that later reverted. Ask the user to check the quota page before big runs.

**Rules:**
- **Daily limit:** 1 leaderboard submission per UTC day. Submissions before 00:00 UTC are refused with HTTP 400; "0 submissions remaining today" means the slot is used.
- **Never heavy compute on the Mac** (no torch, model or FSDP); use Kaggle CPU kernels. Light tokenizer work is OK (`.venv-tok`, `data/g4tok`).
- **Never create, print or handle Kaggle or API tokens.** If my shell says "Authentication required", the user runs `.venv/bin/kaggle auth login --force` themselves.
- **Every eval notebook has a watchdog.**
  - Per-chunk timeout: 8 × (task limit + 3 min).
  - A hard kill at `--budget-h` + 15 min, saving `partial_eval.tgz`.
  - Always set `--budget-h` below the account's remaining quota ÷ 2.
- **Never cut `max_output_tokens` below 8192 with thinking on.** v14's longest response was 5,913 tokens and the thinking budget is soft; v15 crashed this way.
- **Credit public recipes** in submission messages (v15, v17).

**Tooling:**
- `submissions/<name>/` → `tools/make_zip.py` → `dist/<name>/submission.zip`.
- Validate on CPU with `kaggle/validate/make_validate_kernel.py <name>`, then push `kaggle/validate`.
- Submit: `.venv/bin/kaggle competitions submit gemma-4-developer-agent -f dist/<name>/submission.zip -m "..."`.
- The local eval builder is `kaggle/eval_l4/make_eval_notebook.py` (flags: `--valid-only --valid-file`, `--budget-h`, `--gate`, `--necessity`, `--adapter-from`). `KAGGLE_OWNER=atulbaliyan` builds Atul's notebooks.
